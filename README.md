## Contributions

1. Fork repository:

`git clone https://github.com/NicolasPloza/unq-ingles2.git`

2. Creat your branch and make your changes:

`git checkout -b feature/<branch-name>`

3. Commit and push:

`git add .`<br>
`git commit -m "mensaje"`<br>
`git push origin feature/nombre`<br>

4. Make a Pull Request to the main branch
